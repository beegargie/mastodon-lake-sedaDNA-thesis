# Mastodon Lake thesis — R analysis and figure scripts

This folder contains the final R scripts used for the Mastodon Lake sedimentary ancient-DNA (sedaDNA) analyses and thesis figures.

## Directory setup

Run the scripts with this folder as the R working directory. The workflow creates three folders automatically:

- `derived_data/` — intermediate R objects used by downstream scripts
- `figures/` — thesis figure files
- `tables/` — analysis summaries and supporting tables generated by the scripts

### Required input files

Place the following files in the working directory before running the workflow:

- `genus_meta.rds` — genus-level metaDMG/LCA output used for the plant analyses
- `family_meta.rds` — family-level metaDMG/LCA output used for the vertebrate analysis
- `SS0203_sample_metadata.tsv` — library metadata and composite master depths
- `SS0203_plant_functional_groups.tsv` — curated plant functional-group and ecological classification table
- `SS0203_library_QC_full.tsv` — library-level sequencing QC, including `reads_sequenced` and `pct_mapped_euk`
- `age_model_MST.csv` — working Mastodon Lake depth-age lookup

These are **inputs**, not tables generated by the R scripts. If repository permissions and file-size limits allow, they should be archived with the scripts so the workflow can be rerun. If any cannot be shared, their absence and access restrictions should be documented.

The upstream sequence-processing pipeline is not rerun by these R scripts. The R workflow begins from the genus- and family-level classification/authentication outputs listed above.

## Script order

1. `00_config.R`  
   Shared paths, authentication thresholds, chronology functions, plotting helpers, functional-group definitions, and analysis settings.

2. `01_prepare_genus_data.R`  
   Creates the authenticated 280-genus plant community dataset and the shared R objects used by downstream plant analyses.

3. Thesis figure scripts:

   - `Figure_01_climatic_context.R` — Figure 1
   - `Figure_04_library_QC.R` — Figure 4
   - `Figure_05_plant_diversity.R` — Figure 5; includes the rarefaction analysis, repeated random rarefaction for Shannon and inverse Simpson diversity, and GAM trend fitting
   - `Figure_06_dominant_genera.R` — Figure 6
   - `Figure_07_functional_groups.R` — Figure 7
   - `Figure_08_NMDS_CONISS_zones.R` — Figure 8; also writes six-zone membership, zone summaries, and genus-zone association results
   - `Figure_10_vertebrate_detections.R` — Figure 10; creates permissive (>=10 reads per library × family) and strict (>=100 reads per library × family) family detections and calculates the sequencing-depth correlations reported in the Results
   - `Figure_11_paleoecological_synthesis.R` — Figure 11; run after Figure 10 because it uses the permissive vertebrate detection table
   - `Figures_12_13_CONISS_diagnostics.R` — Appendix Figures 12 and 13
   - `Figures_14_19_damage_profiles.R` — Appendix Figures 14–19

All CONISS scripts use the final thesis convention: **Zone A is the deepest/oldest zone and Zone F is the shallowest/youngest zone.**

## Thesis Table 1

The CONISS zone table presented as Table 1 in the thesis is a descriptive synthesis rather than a direct formatted output from one script. The quantitative zone membership, depth ranges, modeled ages, and genus-zone associations supporting the table are generated by `Figure_08_NMDS_CONISS_zones.R` and written to the `tables/` directory.

Because the formatted Table 1 is already included in the thesis, a separate repository copy is not required. A machine-readable `Table_01_CONISS_zones.tsv` may be added as a convenience if an exact standalone version of the thesis table is desired.

## Reproducibility notes

The primary plant authentication thresholds are `A >= 0.05` and `Zfit >= 2`. The retained plant community contains the curated 280 genera used in the thesis, each with at least 100 authenticated abundance reads across the dataset. Plant abundance is based on `total_n_reads_from_mD` after authentication.

Rarefaction retains approximately 80% of non-zero sediment libraries and is repeated 100 times for Shannon and inverse Simpson diversity. NMDS uses Hellinger-transformed counts, Bray-Curtis dissimilarity, two dimensions, and a fixed random seed. CONISS uses Hellinger-transformed community data and Euclidean distance.

The vertebrate figure uses native family-rank assignments from `family_meta.rds`. Permissive detections require at least 10 authenticated reads within a library × family combination; strict detections require at least 100.

## Software versions

The R package versions used for the frozen final analyses are recorded in:

- `package_versions.tsv`

The R version, operating-system/platform information, and full session details should also be archived in:

- `sessionInfo.txt`

Generate `sessionInfo.txt` from the same R environment used for the final analyses before updating R or any installed packages:

```r
writeLines(
  capture.output(sessionInfo()),
  "sessionInfo.txt"
)
```

`package_versions.tsv` records the principal R packages used by the workflow. `sessionInfo.txt` provides the complementary R and platform information, so the package-version list does not need to be duplicated in this README.

If the upstream bioinformatics tools are still available in the Conda environment used for sequence processing, the environment can also be preserved from the command line:

```bash
conda env export --no-builds > environment.yml
conda list --explicit > conda-spec.txt
```

These files document the software environment without changing it.
